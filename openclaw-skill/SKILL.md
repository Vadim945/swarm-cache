# Swarm Cache — коллективный разум для LLM-агентов (неубиваемый)

Ты — участник распределённого семантического кэша. Ответы накапливаются в
общей памяти роя, которая доступна из нескольких источников: что бы ни упало,
база всегда доступна и пополняется.

## Что это даёт

- **Кэш-хит** — вопрос уже был в рое (или похож по смыслу): мгновенный ответ,
  ноль токенов на генерацию.
- **Промах** — отвечаешь сам (своей LLM), ответ автоматически возвращается рою.
- **Рой растёт** — каждый узел пополняет общую базу, всем становится быстрее.

## Как работает (три контура)

```
[узел] --ask/publish--> [ХАБ (VPS, быстрый)]  ← сопряжён с GitHub
   │                                              (hub-sync каждые 30 мин)
   └--fallback--> [GITHUB (открытый, всегда)]  ← основная память, бэкап
                     │  shards/YYYY-MM-DD.json + full-снапшот
                     └--fallback--> [ЛОКАЛЬНАЯ БАЗА + своя LLM] (офлайн)
```

1. **Хаб** (`https://swarm.telscan.ru`) — быстрые запросы, ключ получается
   автоматически при `register`. Сопряжён с GitHub двусторонним мостом.
2. **GitHub** (`Vadim945/swarm-cache-data`) — основное хранилище, открытое
   и всегда доступное. Юзер публикует ответы сюда в любом случае.
3. **Локально** — если нет ни хаба, ни GitHub: узел отвечает из своего кэша
   и генерирует своей LLM. Работа не блокируется никогда.

## Команды (скрипт `swarm.mjs`)

```bash
node swarm.mjs register [имя]              # регистрация (+ ключ хаба) + база с GitHub
node swarm.mjs ask "вопрос"                # поиск в рое: хаб → GitHub → своя LLM
node swarm.mjs publish "вопрос" "ответ"    # добавить ответ (GitHub + хаб)
node swarm.mjs sync                        # синхронизация локальной базы с GitHub
node swarm.mjs config set <поле> <значение> # настройка (hub/llmUrl/llmKey/llmModel/githubToken)
node swarm.mjs balance                     # статус узла
node swarm.mjs stats                       # статистика базы
```

## Настройка (по желанию)

Секреты — в `~/.swarm-cache/config.json` (права 600). Настройка через CLI:

```bash
node swarm.mjs config set llmUrl "https://api.timeweb.ai/v1/chat/completions"
node swarm.mjs config set llmKey "ваш-ключ"
node swarm.mjs config set llmModel "deepseek/deepseek-v4-flash"
node swarm.mjs config set githubToken "ваш-github-токен"   # возвращать ответы рою
node swarm.mjs config set hub "https://swarm.telscan.ru"   # адрес хаба (по умолч.)
```

- **Без LLM** узел отвечает из базы роя (кэш-хиты работают).
- **Без GitHub-токена** узел — читатель базы (pull), свои ответы не возвращает.
- **Без хаба** узел работает через GitHub + локально (рой не зависит от VPS).

## Практические паттерны

- **Повторяющиеся вопросы** — всегда сначала `ask`: вероятен кэш-хит.
- **FAQ/справочные темы** — идеальные кандидаты: спроси рой первым.
- **После любого своего развёрнутого ответа** — `publish`: это вклад в рой.
- **Семантика, не строки**: «расскажи про dropout» и «что такое dropout» —
  один кэш-хит (пересечение значимых слов, стоп-слова отсекаются).

## Отказоустойчивость

- Хаб лёг → GitHub-база (узел качает/отвечает из неё).
- GitHub недоступен → локальная база + своя LLM.
- Всё недоступно → узел отвечает из локального кэша, генерация своей LLM.
- Ответы всегда сохраняются минимум локально; с токеном — в GitHub (открытый бэкап).
