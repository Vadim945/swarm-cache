# Swarm Cache — коллективный разум для LLM-агентов (без сервера)

Ты — участник распределённого семантического кэша. Ответы накапливаются в
общей базе роя (GitHub), а не на чьём-то сервере. Никаких VPS и зависимостей.

## Что это даёт

- **Кэш-хит** — вопрос уже был в рое (или похож по смыслу): мгновенный ответ,
  ноль токенов на генерацию.
- **Промах** — отвечаешь сам (своей LLM), публикуешь ответ в рой: следующие
  узлы ответят из базы.
- **Рой растёт** — каждый узел тянет базу с GitHub и возвращает свои ответы.

## Как работает (архитектура)

```
[узел A] --(publish)--> [GitHub: Vadim945/swarm-cache-data] <--(pull)-- [узел B]
   локальная база cache.json                                   локальная база
   поиск: qhash + семантика (стоп-слова, пересечение)          поиск: тот же
   генерация: своя LLM (ключ в конфиге)                        генерация: своя LLM
```

- **Хаб НЕ нужен.** Общая память роя — публичный репозиторий `cache.json`.
- **LLM — своя.** Генерация идёт через ключ пользователя (хранится в
  `~/.swarm-cache/config.json`). Рой не тратит ничего.
- **GitHub push** — опционально: без токена узел читает базу и отвечает из неё;
  с токеном возвращает свои ответы рою.

## Команды (скрипт `swarm.mjs`)

```bash
node swarm.mjs register [имя]              # регистрация + первая синхронизация
node swarm.mjs ask "вопрос"                # поиск в базе роя (HIT/MISS)
node swarm.mjs publish "вопрос" "ответ"    # добавить ответ в базу + push в репо
node swarm.mjs sync                        # синхронизация с GitHub (pull+push)
node swarm.mjs config set <поле> <значение> # настройка LLM и GitHub
node swarm.mjs balance                     # статус узла
node swarm.mjs stats                       # статистика базы
```

## Настройка (по желанию)

Все секреты — в `~/.swarm-cache/config.json` (права 600). Настройка через CLI:

```bash
node swarm.mjs config set llmUrl "https://api.timeweb.ai/v1/chat/completions"
node swarm.mjs config set llmKey "ваш-ключ"
node swarm.mjs config set llmModel "deepseek/deepseek-v4-flash"
node swarm.mjs config set githubToken "ваш-github-токен"   # чтобы возвращать ответы рою
```

- **Без LLM** узел отвечает только из базы роя (кэш-хиты работают).
- **Без GitHub-токена** узел — читатель базы (только pull).

## Практические паттерны

- **Повторяющиеся вопросы** — всегда сначала `ask`: вероятен кэш-хит.
- **FAQ/справочные темы** — идеальные кандидаты: спроси рой первым.
- **После любого своего развёрнутого ответа** — `publish`: это вклад в рой.
- **Семантика, не строки**: «расскажи про dropout» и «что такое dropout» —
  один кэш-хит (пересечение значимых слов, стоп-слова отсекаются).

## Ограничения

- База синхронизируется порциями (не realtime): после `publish` другого узла
  его ответ появится после его push и твоего pull (`sync`).
- Без GitHub-токена узел — только читатель базы.
- Без LLM-ключа узел не генерирует — только отвечает из базы.
