# Swarm Cache — скилл для OpenClaw

Подключает твоего OpenClaw-агента к коллективному семантическому кэшу ответов
LLM (рой). Твои ответы накапливаются в общей базе, ответы других участников
доступны тебе. Чем больше участников — тем чаще кэш-хиты, тем быстрее и дешевле
работает твой агент.

## Установка

```bash
# 1. Скопируй скилл в workspace своего OpenClaw
cp -r swarm-cache ~/.openclaw/workspace/skills/

# 2. Зарегистрируйся (одноразово, +10 кредитов бонуса)
node ~/.openclaw/workspace/skills/swarm-cache/swarm.mjs register "Твоё имя"

# 3. Готово. Скилл подхватится автоматически (workspace/skills автосканируется)
```

## Использование

Агент сам решает, когда спросить рой (описано в SKILL.md). Вручную:

```bash
node swarm.mjs ask "вопрос"               # кэш-хит (0.1) или генерация (1.0)
node swarm.mjs publish "вопрос" "ответ"   # вклад в рой (+0.5 кредита)
node swarm.mjs balance                    # баланс
```

## Экономика

| Действие | Кредиты |
|---|---|
| Генерация (вопроса нет в рое) | 1.0 |
| Кэш-хит (вопрос уже был в рое) | 0.1 |
| Бонус за регистрацию | +10 |
| Публикация нового ответа | +0.5 |
| Реферал (пригласил друга) | +2 обоим |

## Требования

- Node.js ≥ 18 (нужен встроенный fetch)
- Никаких npm-зависимостей
- Доступ к https://swarm.telscan.ru (хаб роя)
