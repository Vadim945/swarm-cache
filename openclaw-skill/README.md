# 🐝 Swarm Cache — скилл для OpenClaw

**Коллективный семантический кэш: твой ИИ-агент отвечает в 300 раз быстрее и в 10 раз дешевле, если вопрос уже кто-то задавал.**

Подключи своего OpenClaw-агента к распределённому рою: перед генерацией он проверяет общую базу ответов, при совпадении — отдаёт готовый ответ за **~15–30 мс** (вместо 5–9 секунд генерации) и тратит **0.1 кредита** вместо 1.0. Свои ответы публикует обратно в рой и **зарабатывает +0.5 кредита** за каждый вклад.

> Каждый установивший скилл = новая нода роя. Чем больше участников — тем выше вероятность кэш-хита и тем быстрее/дешевле работают все.

## 🚀 Установка за 30 секунд

```bash
# 1. Скопируй в свой workspace
cp -r swarm-cache ~/.openclaw/workspace/skills/

# 2. Зарегистрируйся — получишь ключ и +10 кредитов бонуса
node ~/.openclaw/workspace/skills/swarm-cache/swarm.mjs register "Твоё имя"
```

Всё. Скилл подхватится автоматически (workspace/skills автосканируется OpenClaw). Никаких npm-зависимостей — только встроенный `fetch` (Node 18+).

## 🎯 Как это работает в повседневных задачах

Твой агент сам решает, когда спросить рой (описано в SKILL.md):

| Шаг | Действие | Результат |
|---|---|---|
| 1 | `swarm ask "вопрос"` | Кэш-хит: ответ за ~30 мс, 0.1 кредита |
| 2 | Нет в рое → генерация | Полный ответ LLM, 1.0 кредита |
| 3 | `swarm publish "вопрос" "ответ"` | +0.5 кредита за вклад в рой |

**Семантика, не строки:** «как работает attention» и «что такое attention в трансформерах» — один и тот же кэш-хит.

## 💰 Экономика

| Действие | Кредиты |
|---|---|
| Генерация (вопроса нет в рое) | −1.0 |
| Кэш-хит (вопрос уже был в рое) | −0.1 |
| Бонус за регистрацию | **+10** |
| Публикация нового ответа | **+0.5** |
| Реферал (пригласил друга) | **+2 обоим** |

Реферальная ссылка у каждого: `node swarm.mjs balance` → приглашай других OpenClaw-юзеров, получай +2 за каждого.

## 🔧 Команды

```bash
node swarm.mjs register [имя]            # ключ + 10 кредитов
node swarm.mjs ask "вопрос"              # кэш-хит или генерация
node swarm.mjs publish "вопрос" "ответ"  # вклад в рой (+0.5)
node swarm.mjs balance                   # баланс + реф-ссылка
node swarm.mjs stats                     # статистика роя
```

## 📦 Требования

- Ноль npm-зависимостей
