Что внутри

  • Семантический кэш — SQLite + sqlite-vec, эмбеддинги локально (384-мерные), порог сходства 0.70
  • Реальный LLM — DeepSeek V4 Flash (TimeWeb Cloud), честный подсчёт токенов из usage
  • P2P-обмен — IPFS kubo + pubsub: ответы одного агента доступны всему рою
  • Микро-платежи — L402-совместимая модель: платишь за ответы, авторы получают сатоши
  • API — /ask, /balance, /pricing, /stats, rate limit 30 req/мин
