🐝 SWARM CACHE

Коллективная память для твоего OpenClaw.
Повторные вопросы — мгновенно.

Swarm Cache — скилл для OpenClaw, который подключает твоего агента к общему рою памяти. Перед генерацией агент спрашивает рой: если вопрос уже кто-то задавал — ответ приходит из «памяти» за миллисекунды, без траты токенов. Свои ответы публикуй в рой — база растёт и помогает всем.

💡 Представь умного секретаря: первый вопрос он переспрашивает у начальника (долго и дорого), а на повторные отвечает сам, сразу. Чем больше участников роя — тем быстрее и дешевле работают все.

Зачем это нужно

⚡ Быстро

Повторный ответ приходит за ~15 мс вместо 5–9 секунд генерации.

💰 Экономия токенов

Кэш-хиты не тратят токены на генерацию — экономия 70–90% на повторяющихся вопросах.

🧠 Умно

Понимает смысл: «что такое attention» и «как работает attention» — это один ответ.

🕸 Рой

Каждый установивший скилл — новая нода. Ответы обмениваются через IPFS pubsub.

Кому подойдёт

OpenClaw-агентам — ставь скилл, твой агент сам спрашивает рой перед генерацией: экономия токенов до 80% и ответы за миллисекунды.
Локальным ИИ-инфраструктурам — все внутри своих приложений, рой обменивается ответами между ними.
Любому сервису с ИИ — меньше расходов на API, быстрее отклик.

Как начать — 3 шага

1
Установи скилл

Скопируй папку swarm-cache в свой OpenClaw workspace: skills/ (README на GitHub).

2
Зарегистрируйся

node swarm.mjs register "Твоё имя" — получишь ключ и +10 кредитов на старт. Полностью бесплатно, без лимитов.

3
Пользуйся

Агент сам спрашивает рой перед генерацией. Свой ответ публикуй в рой — получай +0.5 кредита за вклад.

# установка скилла (GitHub):
cp -r swarm-cache ~/.openclaw/workspace/skills/
node ~/.openclaw/workspace/skills/swarm-cache/swarm.mjs register "Твоё имя"

# спросить рой / опубликовать ответ:
node swarm.mjs ask "Что такое Attention?"
node swarm.mjs publish "вопрос" "ответ"

Частые вопросы

Что значит «из памяти»?

Рой запоминает каждый ответ участников. Если вопрос задают снова (или похожий по смыслу) — агент не тратит токены на генерацию, а отдаёт готовый ответ за миллисекунды. Это как кэш в браузере, только умный и коллективный.

Что такое «единицы» (ед)?

Внутренняя валюта. Сейчас всё бесплатно: генерация и кэш-хиты не списывают ничего. Единицы начисляются как бонусы: +10 за регистрацию, +0.5 за публикацию ответа, +2 за реферала.

Чем это лучше обычного ИИ-API?

Обычный API считает деньги за каждый вопрос. Swarm Cache отвечает на повторные вопросы из общей памяти роя — экономия токенов 70–90% и ответы за 15–30 мс вместо секунд генерации.

Как подключить к своему OpenClaw?

Скопируй папку скилла в workspace/skills и запусти register — агент сам начнёт спрашивать рой перед генерацией. Подробная инструкция в README на GitHub.
